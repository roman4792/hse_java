# Матрицы комплексных чисел

Консольное приложение на Java для работы с матрицами комплексных чисел. Поддерживаются операции: сложение, умножение, деление, транспонирование, вычисление определителя.

## Состав проекта

| Файл | Назначение |
|------|-----------|
| `Complex.java` | Комплексное число и арифметика над ним |
| `ComplexMatrix.java` | Матрица комплексных чисел и матричные операции |
| `Main.java` | Консольный интерфейс (меню, ввод, вывод) |

## Архитектура

Классы образуют три уровня. Каждый уровень использует только нижестоящий:

```
Main  ->  ComplexMatrix  ->  Complex
```

- **Complex** хранит действительную и мнимую части. Объекты неизменяемы: операции `add`, `subtract`, `multiply`, `divide` возвращают новый объект. Деление на ноль вызывает `ArithmeticException`. Значения с модулем менее `1e-9` считаются нулевыми.
- **ComplexMatrix** хранит двумерный массив `Complex[][]`. При недопустимых размерах операции выбрасывают исключение с описанием причины.
- **Main** хранит созданные матрицы в списке и вызывает методы `ComplexMatrix`. Результат каждой операции сохраняется как новая матрица с очередным номером.

## Реализация операций

| Операция | Метод | Условие выполнения |
|----------|-------|--------------------|
| Сложение | поэлементное | размеры матриц совпадают |
| Умножение | строка на столбец | число столбцов первой равно числу строк второй |
| Транспонирование | `result[j][i] = data[i][j]` | без ограничений |
| Определитель | метод Гаусса с выбором главного элемента | матрица квадратная |
| Обратная матрица | метод Гаусса-Жордана | матрица квадратная и невырожденная |
| Деление `A / B` | `A * B^(-1)` | B квадратная и невырожденная, число столбцов A равно размеру B |

## Работа с программой

1. Выбрать в меню пункт «Создать матрицу» и указать число строк и столбцов.
2. Каждый элемент вводится двумя числами через пробел: действительная и мнимая части. Пример: `3 -1` соответствует числу `3 - 1i`.
3. Дробная часть отделяется точкой (`2.5`).
4. Для операции указываются номера матриц. Результат выводится на экран и сохраняется под новым номером.

## Запуск на Windows

**Требования:** установленный JDK версии 8 или выше; путь к нему добавлен в переменную `PATH` (проверка: `javac -version`).

**Порядок запуска из командной строки** в каталоге с файлами проекта:

```
chcp 65001
javac -encoding UTF-8 *.java
java Main
```

- `chcp 65001` включает кодировку UTF-8 в консоли.
- Параметр `-encoding UTF-8` необходим, так как исходные файлы содержат русский текст в кодировке UTF-8.
- При некорректном отображении русских символов на Java 17 и ниже следует использовать команду `java -Dfile.encoding=UTF-8 Main`, либо запускать проект из среды разработки (IntelliJ IDEA, Eclipse, VS Code).

**Возможные ошибки:**

| Сообщение | Причина |
|-----------|---------|
| `javac` не распознан | JDK не установлен или отсутствует в `PATH` |
| `Could not find or load main class Main` | проект не скомпилирован или запуск выполнен из другого каталога |
| «Это не число, попробуйте ещё раз» | в качестве разделителя дробной части использована запятая |

## Ограничения

- Транспонирование выполняется без комплексного сопряжения.
- Точность вычислений ограничена типом `double`.
- Данные не сохраняются после завершения программы.
